ANSWER IN THIS ORDER

1. IDENTITY AND AVAILABILITY
   Official name vs. the name people use, developer, release date, architecture (DiT, MoE,
   single-stream omni-transformer, causal/autoregressive), parameter count, prediction type
   (flow matching / rectified flow / other).
   Then, critically: WHICH versions have downloadable weights and which are API-only. Give

2. COMPONENTS

     VRAM cost of decode at target length, known decode artifacts.

     bilingually and behave differently in English vs. Chinese prompts).
   - Image/vision encoder used for image conditioning, if separate.
   - Audio encoder/decoder, if the model handles audio.
   - Which components can be quantized or swapped, and which cannot.

3. DURATION, FRAME COUNT, RESOLUTION, FPS

   - Supported resolutions and aspect ratios, whether portrait is natively trained or
     cropped from landscape, and the resolution × duration × VRAM trade-off.
   - Whether fps is a real conditioning parameter or just export metadata.

     drift, or hard failure.

5. PARAMETERS — per variant

   resolution and length — give the actual recommended values, not a range.
   Cover step-reduction LoRAs and distilled variants: what they cost in motion quality,

   Then a known-good starting recipe per variant, and which single parameter most often
   causes the "why is my output a slideshow" failure.

6. PROMPTING
   - Structure that works: subject, action, camera, lighting, style — in what order, and

   - Whether an official prompt extender / rewriter LLM is part of the intended pipeline,

   - Default or recommended negative prompt, including whether the official one is in

   - How to describe temporal progression within one clip, and whether the model can follow

   - Two concrete example prompts at the length the model actually wants.

7. GENERATION MODES
   For each: native / extra weights / community hack / not supported —
   text-to-video, image-to-video (start frame), first-and-last-frame, video-to-video,

8. STRUCTURAL AND REFERENCE CONTROL
   The video equivalent of ControlNet — state plainly whether anything usable exists.

   - Which control signals work: pose, depth, canny/edge, optical flow or motion tracks,

   - Camera control: explicit trajectory conditioning vs. prompt-only.
   - Identity/character consistency across generations, and the recommended method.
   - Recommended strengths and step ranges, and how control interacts with distilled

9. COMPOSITIONAL AND TEMPORAL PROMPT CONTROL
   Regional prompting is mostly meaningless here; tell me what replaces it.

   - Per-shot prompting for multi-shot output, and whether continuity holds across cuts.

10. AUDIO
